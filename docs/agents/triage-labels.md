# Triage Labels

Default label vocabulary:

| Label                 | Meaning                       |
|-----------------------|-------------------------------|
| `ready-for-agent`     | Fully specified, ready for AFK agent |
| `needs-triage`        | Maintainer needs to evaluate  |
| `needs-info`          | Reporter information still missing |
| `ready-for-human`     | Requires human implementation |
| `done`                | Completed and no longer active |
| `wontfix`             | No longer planned             |
